مرکز عملیات تجارت دریایی بریتانیا (UKMTO) نیز در هشدار شماره ۱۹۶ از اصابت دو پرتابه ناشناس به یک نفتکش در حدود ۵۰ مایل دریایی شمال قطر خبر داده بود.
