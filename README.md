فایننشال تایمز روز چهارشنبه گزارش داده بود که نتانیاهو خواستار ازسرگیری عملیات نظامی علیه ایران شده بود، اما ترامپ با این اقدام پیش از انتخابات میان‌دوره‌ای آمریکا در ۱۲ آبان مخالفت کرده است.
